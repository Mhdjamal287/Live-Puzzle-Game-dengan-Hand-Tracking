# Live Puzzle Game dengan Hand Tracking

Project puzzle interaktif menggunakan webcam dan hand tracking untuk mengatur ukuran puzzle.

## Instalasi

```bash
pip install -r requirements.txt
```

## Cara Main

```bash
python live_puzzle_single.py
```

### Instruksi:
1. **Setup**: Tunjukkan 2 tangan, atur jarak jari telunjuk untuk ukuran grid (2x2 - 5x5)
2. **Cubit** (jari telunjuk + ibu jari) untuk mulai puzzle
3. **Klik 2 kotak** untuk swap posisi
4. Susun puzzle sampai selesai!

### Kontrol:
- **Q** = Keluar
- **R** = Main lagi (saat mode puzzle)
